# ひとり麻雀 練習対局 PWA

自分のiPhoneだけで遊ぶことを想定した、シンプルな麻雀練習アプリです。Safariで開いて「ホーム画面に追加」すると、アプリのように起動できます。

## 追加済み機能

- CPU3人との東風戦形式
- 配牌、ツモ、打牌、捨て牌表示
- リーチ宣言
- 鳴き：ポン / チー / カン
- ロン / ツモ和了
- 高度化したCPU思考
  - 受け入れ枚数の簡易評価
  - 形の維持
  - リーチ者への現物・危険牌評価
  - ドラ周辺の危険度評価
- 役判定
  - リーチ
  - 門前清自摸和
  - 断么九
  - 役牌
  - 七対子
  - 対々和
  - 平和
  - 一盃口
  - 混一色
  - 清一色
  - ドラ加算
  - 国士無双
  - 四暗刻
  - 大三元
  - 小四喜 / 大四喜
  - 字一色
  - 清老頭
  - 緑一色
  - 四槓子
  - 九蓮宝燈
- 点数計算
  - 翻 / 完全寄りの符計算
  - 副底、門前ロン、ツモ符、雀頭符、刻子符、槓子符、七対子25符
  - 満貫、跳満、倍満、三倍満、役満相当
  - ロン / ツモ / 親子支払い
  - 供託リーチ棒
  - 本場の加点
- 初心者ガイド
- 対局ログ
- オフライン対応Service Worker

## iPhoneで使う方法

1. このフォルダを GitHub Pages / Vercel / Netlify / Cloudflare Pages などにアップロードします。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタンを押します。
4. 「ホーム画面に追加」を選びます。
5. ホーム画面のアイコンから起動します。

## ローカル確認方法

PCで確認する場合は、フォルダ内で簡易サーバーを起動します。

```bash
python -m http.server 8000
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8000
```

## 注意

学習用にわかりやすさを優先した実装です。実戦麻雀と完全一致しない簡略化があります。

- カンは暗槓・大明槓・加槓に対応
- フリテンは自分の捨て牌による永久フリテンとロン見送り時の一時フリテンに対応
- 喰い替えは禁止処理を実装
- CPU思考は受け入れ・形・安全度を加味
- 符計算は主要な符を内訳つきで計算
- 役満は主要役満を個別判定

簡略化として、ダブルロン/トリプルロン、搶槓、海底/河底、一発、嶺上開花の役付与、途中流局、細かなローカルルールまでは省略しています。
